How to use Patcher

1. Overview

Patcher applies exact character find-and-replace blocks from LLM markdown into your project file. Paste the AI's entire markdown response into the center box—conversational filler before and after patches is automatically ignored.

2. Markdown Patch Syntax

Your LLM should follow either format without abbreviations or truncation:

Standard Patch (Local edits): 
Patch 1/2
Find
```html
<div class="header">Old Code</div>
```
Replace with
```html
<div class="header">New Code</div>
```
Range Patch (Multi-line / Large refactors): 
Patch 2/2
Find start
```javascript
function init() {
```
Find end
```javascript
    ready = true;
}
```
Replace with
```javascript
function init() {
    setupEngine();
    ready = true;
}
```
